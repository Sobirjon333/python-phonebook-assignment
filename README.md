# Телефонная книга

Консольное приложение на Python для хранения и поиска контактов.

## Возможности

- просмотр всех контактов;
- добавление нового контакта;
- поиск по имени;
- сохранение данных в `data/contacts.json`.

## Запуск

Требуется Python 3.10 или новее.

```bash
python3 phonebook.py
```

Проект использует только стандартную библиотеку Python, поэтому установка зависимостей не нужна.
